# 🇰🇷 국내 장소 정보 모음

국내 카페, 음식점, 여행지 정보를 쉽게 수집하고 관리할 수 있는 웹 애플리케이션입니다.

## ✨ 주요 기능

- **장소 추가**: 카페, 음식점, 여행지 정보를 간편하게 등록
- **카테고리 분류**: 세 가지 카테고리로 장소를 체계적으로 관리
- **평점 시스템**: 1~5점 별점으로 장소 평가
- **태그 기능**: 장소의 특징을 태그로 표시
- **검색 & 필터**: 장소명, 위치로 검색하고 카테고리별 필터링
- **통계 대시보드**: 카테고리별 장소 수 실시간 확인
- **로컬 저장**: 브라우저 로컬 스토리지에 데이터 자동 저장

## 🚀 시작하기

### 설치

별도의 설치 과정이 필요 없습니다. 웹 브라우저만 있으면 사용할 수 있습니다.

### 사용 방법

1. `index.html` 파일을 웹 브라우저로 엽니다
2. 또는 로컬 서버를 실행합니다:
   ```bash
   # Python 3를 사용하는 경우
   python -m http.server 8000

   # Node.js http-server를 사용하는 경우
   npx http-server
   ```
3. 브라우저에서 `http://localhost:8000` 접속

## 📝 사용 예시

### 장소 추가하기

1. "새 장소 추가" 섹션에서 정보 입력
   - 장소명: 필수
   - 카테고리: 카페/음식점/여행지 중 선택
   - 위치: 필수
   - 평점: 선택사항 (1~5점)
   - 설명: 선택사항
   - 태그: 쉼표로 구분 (예: 조용한, 넓은, 주차가능)
2. "장소 추가" 버튼 클릭

### 장소 검색 및 필터링

- **카테고리 필터**: 드롭다운에서 원하는 카테고리 선택
- **검색**: 검색창에 장소명 또는 위치 입력
- **삭제**: 각 장소 카드의 "삭제" 버튼 클릭

## 💾 데이터 저장

모든 데이터는 브라우저의 로컬 스토리지에 자동으로 저장됩니다.
브라우저를 닫았다가 다시 열어도 데이터가 유지됩니다.

⚠️ **주의**: 브라우저 캐시를 삭제하면 데이터도 함께 삭제됩니다.
